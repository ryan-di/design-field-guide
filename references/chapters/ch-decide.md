# Chapter 28 · Decide with judgment, not by polish

> Evidence boundary: this is a learning guide. Its demos and product examples are illustrations written for the book, not verified product documentation, so check a product’s own docs before citing how it behaves. Tools named in it are 2026 examples, not endorsements.

Agents can make every direction look finished, so polish no longer tells you which one is right. Score directions against the brief, check each one hard, and keep only the parts that hold up.

## Entries

- [Decision matrix](../entries/eff-decision-matrix.md): A decision matrix scores each direction from 1 to 5 against each criterion in the brief.
- [Spot the plausible](../entries/eff-spot-plausible.md): Agent-made screens often look finished and still have problems: vague copy, a broken keyboard path, a missing state, or a color a little off the design tokens.
- [Cut and combine](../entries/eff-cut-combine.md): When you have several design directions, the best answer is often none of them whole: it takes the strongest part of each and cuts the rest.
