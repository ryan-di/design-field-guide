# Chapter 8 · Too much at once

> Evidence boundary: this is a learning guide. Its demos and product examples are illustrations written for the book, not verified product documentation, so check a product’s own docs before citing how it behaves. Tools named in it are 2026 examples, not endorsements.

A panel with twenty settings asks people to judge all twenty before they can do anything, so they freeze, skim, or miss the one setting that mattered. The patterns in this chapter show the basics first and keep the rest one step away, so the screen starts simple and nothing is out of reach.

## Entries

- [Progressive disclosure](../entries/pat-progressive-disclosure.md): Progressive disclosure shows the settings most people need first and keeps the rest one step away, so people can start without judging every option on the screen.
- [Smart defaults](../entries/pat-smart-defaults.md): A smart default is a value filled in for people because it fits most of them, so they can accept it and move on, or change it.
- [Presets](../entries/pat-presets.md): A preset sets several linked values at once, under a name that says what you get, like “Fast” or “Best quality”.
