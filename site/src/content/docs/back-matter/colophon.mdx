Design Field Guide is Book 1 of the design engineer primer. This is version <span id="colophon-version">v35</span>, from November 2026. The [changelog](../../CHANGELOG.md) lists what changed in each version, and the source is on [GitHub](https://github.com/ryan-di/design-field-guide).

The book is one HTML file, with every demo built in. Agents can read the same text, generated from this page, starting from [llms.txt](../../llms.txt).

Companion decks in this primer: [UX Components](https://claude.ai/artifact/DpPreyaUdpLCEz7gdXhByh), [UX Patterns](https://claude.ai/artifact/VryzywoXc2cPqBgTPJafzF) and [Good Design](https://claude.ai/artifact/WiCu9DfPgWgwByp7tLRU15) (slide versions of Parts 1 to 3), and [The Future of Design](https://claude.ai/artifact/Mh7sqnKdPPaf1j1wbgfV9v).
