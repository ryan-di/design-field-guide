> Evidence boundary: this is a learning guide. Its demos and product examples are illustrations written for the book, not verified product documentation, so check a product’s own docs before citing how it behaves. Tools named in it are 2026 examples, not endorsements.

Pick the indicator by how long the wait is: under 400 ms, show nothing; up to about ten seconds, a spinner; longer, real progress.

## Entries

- [Spinner](../entries/spinner.md): A spinner is a small turning circle that says “working on it”.
- [Progress bar](../entries/progress-bar.md): A progress bar is a line that fills as long work gets done: an upload, a download, an export, a backup.
- [Skeleton](../entries/skeleton.md): A skeleton is a gray outline of content that is still loading, with the same boxes and lines as the content that will replace it: a box for each photo, a bar for each line of text.
