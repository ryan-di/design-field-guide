# Chapter 25 · Work in a loop: frame, explore, decide, build, check

> Evidence boundary: this is a learning guide. Its demos and product examples are illustrations written for the book, not verified product documentation, so check a product’s own docs before citing how it behaves. Tools named in it are 2026 examples, not endorsements.

Good work runs in a loop: frame the problem, explore options, decide, build, check, and learn for the next round. Agents can do much of the exploring and building, but the framing, deciding and checking stay yours.

- [The loop](../entries/eff-loop.md): Every change goes through the same loop.
